# Section 10 · Branding — feature folder (v1.7.1)

Source of truth for slides **46 Typography · 47 Brand assets · 48 Product assets** (deep links `#/28/brand-1…3`, also `#slide-46…48`).
The build (`scripts/v1.4.7/build.mjs` → `scripts/v1.7.1/brand-sync.mjs`) verifies every file here by sha256, copies the content-hashed
assets to `dist/assets/brand/`, and GENERATES `dist/js/brand-data.js` (`window.AtharBrandData`) and `dist/assets/brand-fonts.css`.
The runtime module is `dist/js/brand-section.js` (+ `dist/assets/brand-section.css`); it mirrors `dist/js/exec-team.js` and loads before it.

* **47 Brand assets** — `Athar_Logo_Horizontal_transparent_v1.png`; `brand-tokens.json` (extracted from the guidelines); mood board (`image_picker_…1A58.jpg`, identified as the guidelines' key visual), `athar_web_agent_avatar_system_v2.jpg`, brand tile render; `brand-asset-manifest_v1.csv` counts; guidelines ch. 2 rules.

## PENDING BRAND PACK (shown on slide 47)

1. **Athar_Brand_Asset_Pack_v3 manifest** — the supplied `brand-asset-manifest_v1.csv` is the Erth Zayed portfolio web-asset harvest (2026-08-21), not the Athar pack listing.
2. **tokens_v2.json** — the token export named in the guidelines (p. 34) was not supplied; the tokens were re-extracted from the guidelines text instead.
3. **Logo masters** — `Athar_Logo_Primary / Reversed / Monochrome / Monogram` (PNG + SVG, guidelines 2.14) were not supplied; only the horizontal transparent PNG exists, so every other version on slide 47 is DERIVED FROM OFFICIAL LOGO.
4. **Jost Light · Montserrat Light** — the sans display alternates are not self-hosted (no surface in this deck uses them).
5. The supplied `brand-tokens_v1.json` is the *Erth Zayed Philanthropies — Brand Token Pack* (25 entities) and carries no Athar palette; it is not used for any colour.

Brand fonts: all five faces are self-hosted and load (slide 46 shows "Brand fonts loaded (5/5)" from `document.fonts`); the fallback note
"Fallback stack in use — brand font files PENDING BRAND PACK" renders only if `document.fonts.check` fails for any face.

```bash
python3 scripts/v1.7.1/build_brand_assets.py <input dir with the pack files> <dir with the subset woff2 files>
npm run build && node scripts/vercel-build.mjs
```
